# Acceptance Criteria

Write criteria that are testable.

## Format
- **Given** [initial state]
- **When** [action]
- **Then** [expected outcome]

## Example criteria
1. Given a logged-in user, when they submit the form with valid data, then the API returns 200 and the record is created.
2. Given an invalid email, when submitting, then the UI shows a localized error message and the API is not called.

## Required sections
- Functional acceptance criteria
- Security acceptance criteria
- Accessibility acceptance criteria
- Observability acceptance criteria
- Performance acceptance criteria (if applicable)
